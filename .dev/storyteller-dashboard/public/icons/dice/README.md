# Dice faces

Coffin-shaped die faces for rolled dice in the Scenes tab Rolls cell (`scenesPanel/rolls/dice.tsx`, picked by `dieFaceSrc` in `view.ts`). Supplied by the author; originals live in `.dev/Storyteller Dashboard Docs/SVG Dice Icons/`.

- `standard_*` — normal and Werewolf dice: `1-5` blank, `6-9` success, `10` critical.
- `hunger_*` — Hunger, Rage and Rouse dice: `1` bestial, `2-5` blank, `6-9` success, `10` messy critical. Oblivion Rouse dice tint this art blue.
